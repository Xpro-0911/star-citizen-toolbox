## 配乐

`src/music.js` 用 Web Audio 实时合成：弦乐、钢琴、圆号、合唱、钟琴、甘美兰、软槌定音鼓、风声。
72 BPM，D 小调开始，终章转 D 大调。一个 A–D–E–F 的四音母题贯穿全片；两段低谷收成大提琴独奏、钢琴独奏；
没有硬卡点，打击乐只用滚奏渐强和镲片 swell。

## 文件

- `index.html`：浏览器里直接播放（需要 `output/music.m4a`）；`?t=秒数` 从指定时间开始
- `src/timeline.js`：音乐和画面共用的小节时间轴
- `src/shader.js`：各幕 WebGL 背景
- `src/visuals.js`：各幕前景、字幕、合成
- `src/music.js`：配乐
- `tools/render-audio.mjs`：离线渲染配乐 → `output/music.wav`
- `tools/render-video.mjs`：多进程逐帧导出 → `output/moonton_12_years.mp4`
- `tools/preview.mjs`：渲染指定时间点的静帧

## 重新导出

```bash
pip install imageio-ffmpeg          # 自带 x264 的 ffmpeg
node tools/render-audio.mjs          # 约 6 分钟
node tools/render-video.mjs 3 30     # 3 个进程、30fps
```
